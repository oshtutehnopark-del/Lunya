# Луня — уроки для малышей

Ежедневные обучающие мини-мультфильмы (~1 минута) с совушкой Луней.

## Что здесь
| Папка | Содержимое |
|---|---|
| `character/` | Паспорт персонажа (`luna_passport.md`), лист с ракурсами и цветами, вырезанная Луня |
| `videos/` | Готовые выпуски |
| `clips/generated/` | Анимированные сцены (нейросеть Wan 2.2 через Hugging Face) |
| `voice/` | Озвучка Луни (edge-tts, голос ru-RU-SvetlanaNeural, +25 Гц, −8 %) |
| `scripts/` | Скрипты: генерация сцен (`gen_wan.py`) и сборка выпуска (`assemble_luna.py`) |

## Выпуски
1. **Считаем яблоки** — `videos/lunya_schitaem_yabloki.mp4`
2. Первая версия «Считаем до 5» — `videos/sovushka_vypusk_01_anim.mp4`

## Как делается выпуск
1. Сцены: клипы из Kling / CapCut + бесплатная анимация Wan 2.2 (Hugging Face ZeroGPU, ~4 клипа в день).
2. Голос: бесплатный нейросетевой синтез edge-tts.
3. Сборка: Python + Pillow + ffmpeg — счёт, загадки, музыка, звуки, титры.

Ключи и токены в репозиторий не кладутся (см. `.gitignore`).
